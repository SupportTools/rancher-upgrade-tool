Rancher Upgrade Planner

Rancher runs on one cluster and manages others. Both have version requirements, and the one Rancher itself runs on is usually what blocks the upgrade, so this asks for both.

Local cluster — where Rancher itself runs
Downstream clusters — every cluster this Rancher manages

Rancher can only move when every attached cluster sits inside the target version’s support window, so the fleet is planned as a set rather than one cluster at a time.
